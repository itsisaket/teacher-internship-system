# Teacher Internship System

ระบบบริหารการฝึกประสบการณ์วิชาชีพครู สำหรับผู้ดูแลระบบ นักศึกษา อาจารย์นิเทศ และโรงเรียน

## Technology stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Supabase Authentication
- Supabase PostgreSQL
- Vercel

## Version 1 scope

- เข้าสู่ระบบด้วยอีเมลและรหัสผ่าน
- Dashboard แยกตามบทบาท
- จัดการข้อมูลนักศึกษา โรงเรียน ภาคการศึกษา และการจัดสรรสถานที่ฝึกสอน
- บันทึกการนิเทศและผลประเมิน
- รายงานสรุปสำหรับผู้ดูแลระบบ

ดูรายละเอียดที่ `docs/requirements-v1.md` และ `docs/database-design-v1.md`
