# ข้อกำหนดระบบ Version 1

## 1. เป้าหมาย

สร้างเว็บแอปสำหรับจัดการการฝึกประสบการณ์วิชาชีพครู ตั้งแต่การจัดเก็บข้อมูลนักศึกษาและโรงเรียน การจัดสรรสถานที่ฝึกสอน การนิเทศ ไปจนถึงการประเมินผลและรายงานสรุป

## 2. บทบาทผู้ใช้

### ผู้ดูแลระบบ (Admin)

- จัดการบัญชีและบทบาทผู้ใช้
- จัดการข้อมูลโรงเรียนและภาคการศึกษา
- จัดสรรนักศึกษา โรงเรียน และอาจารย์นิเทศ
- ดูสถานะการฝึกสอนทั้งหมด
- ดูรายงานสรุปและผลประเมิน

### นักศึกษา (Student)

- ดูและแก้ไขข้อมูลส่วนตัวที่อนุญาต
- ดูโรงเรียนและอาจารย์นิเทศที่ได้รับมอบหมาย
- ดูกำหนดการและบันทึกการนิเทศของตน
- ดูผลประเมินที่ประกาศแล้ว

### อาจารย์นิเทศ (Supervisor)

- ดูรายชื่อนักศึกษาที่รับผิดชอบ
- สร้างและแก้ไขบันทึกการนิเทศ
- ประเมินนักศึกษาที่อยู่ในความรับผิดชอบ
- ดูประวัติการนิเทศและผลประเมินที่ตนจัดทำ

### โรงเรียน (School)

- ดูนักศึกษาที่ฝึกสอนในโรงเรียนของตน
- ดูข้อมูลการจัดสรรและช่วงเวลาฝึกสอน
- บันทึกผลประเมินของโรงเรียน

## 3. หน้าจอ

- `/` หน้าแนะนำระบบ

- `/reset-password` หน้าตั้งรหัสผ่านใหม่

## 4. ขั้นตอนการทำงานหลัก

1. ผู้ดูแลระบบสร้างภาคการศึกษา โรงเรียน และบัญชีผู้ใช้
2. ผู้ดูแลระบบจัดสรรนักศึกษาไปยังโรงเรียน พร้อมระบุอาจารย์นิเทศและช่วงเวลา
3. นักศึกษาตรวจสอบข้อมูลการจัดสรรของตน
4. อาจารย์นิเทศบันทึกการนิเทศแต่ละครั้ง
5. อาจารย์นิเทศและโรงเรียนบันทึกผลประเมินแยกกัน
6. ผู้ดูแลระบบตรวจสอบภาพรวมและรายงาน
7. นักศึกษาดูผลประเมินเมื่อผลถูกประกาศแล้ว

## 5. ขอบเขตที่ยังไม่รวมใน Version 1

- แอปมือถือแบบ Native
- การชำระเงิน
- การเชื่อมระบบทะเบียนภายนอก
- การสร้างเอกสาร PDF อย่างเป็นทางการ
- การแจ้งเตือนผ่าน LINE, SMS หรืออีเมลอัตโนมัติ
- การแนบไฟล์ขนาดใหญ่และแฟ้มสะสมผลงาน

## 6. เกณฑ์ตรวจรับ

- ผู้ใช้เข้าสู่ระบบและเห็นข้อมูลตามบทบาทของตนเท่านั้น
- ผู้ดูแลระบบสร้างและแก้ไขข้อมูลหลักได้
- นักศึกษาเห็นเฉพาะข้อมูลการฝึกสอนของตน
- อาจารย์นิเทศจัดการได้เฉพาะนักศึกษาที่ได้รับมอบหมาย
- โรงเรียนจัดการได้เฉพาะนักศึกษาของโรงเรียนตน
- คะแนนทุกช่องอยู่ระหว่าง 0 ถึง 100
- หน้าสำคัญใช้งานได้ทั้งคอมพิวเตอร์และโทรศัพท์
- การตรวจรูปแบบโค้ด การตรวจชนิดข้อมูล และ production build ผ่านทั้งหมด
